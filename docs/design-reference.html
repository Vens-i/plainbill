Assumptions
"Plainbill" is a working name — swap freely. All data fictional. Figtree stands in for Inter (same clean, friendly sans). Deep teal is the only brand color; everything else is warm neutral.
PayPal
Striped slots mark where the official PayPal SDK buttons render (Smart Button, Pay Later). We never restyle or imitate them. In email, the slot is PayPal's official static button image.
Status system
Every status = icon + label + color: ! review, × denied, → ready, ↗ sent, ◐ partial, ✓ paid. Aging pills always print their bucket.
